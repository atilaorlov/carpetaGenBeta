# Carpeta Telmex — base Fielder

Plantilla limpia `Solicitud_fielder.pdf` y JSON original sin cambios.

## Probar

Desde esta carpeta ejecuta `python3 -m http.server 8000` y abre `http://localhost:8000`.
También puedes publicar estos archivos en GitHub Pages. Requiere internet para cargar pdf-lib desde CDN.

## Estado real

Solo Fielder está conectado. Aviso de privacidad y portabilidad aún no se generan.
Los datos y las fotos se guardan en IndexedDB de este navegador: no es respaldo entre dispositivos.
La generación final pide folio SIAC e imagen de folio. Revisa el PDF antes de usarlo con clientes.
